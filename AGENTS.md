# Yen Portfolio project rules

- This is a static, dependency-free HTML/CSS/JavaScript portfolio.
- Source facts come from https://www.yen-art.com/ and the verified local CV/profile files.
- Never invent outcomes, metrics, clients, publication status, responsibilities, or software proficiency.
- Keep copy concise, specific, human, and easy to scan. Avoid inflated claims and generic AI-style phrasing.
- Do not modify the live Wix site from this project.
- Remote Wix images are temporary migration sources; preserve source URLs in `assets/js/data.js` until local files replace them.
- Missing case-study evidence must be shown as a labelled content request, not filled with assumptions.
